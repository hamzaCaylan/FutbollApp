Claude Code ile çalışırken en iyi sonuç veren yöntem, her fazın **bağımsız çalışabilir**, **test edilebilir** ve **tek bir amaca odaklı** olmasıdır. Her faz sonunda çalışan bir uygulama elde edersin.

Aşağıdaki planı doğrudan Claude Code'a verebilirsin.

## Claude Code İçin Çalışma Kuralı (Prompt)

Her fazın başına aşağıdaki talimatı eklersen Claude Code daha tutarlı ilerler:

```text
You are building a production-quality football tactics board application.

Rules:
- Complete ONLY the requested phase.
- Do not implement future phases.
- Use reusable components.
- Keep code modular and clean.
- Follow SOLID principles.
- Use TypeScript strictly.
- No mock implementations unless requested.
- Ensure the project compiles successfully before finishing.
- Explain architectural decisions briefly.
- Update folder structure if necessary.
- At the end of the phase provide:
  1. Completed features
  2. Files created
  3. Files modified
  4. Next phase prerequisites
```

Bu yapı sayesinde Claude Code her fazı bağımsız geliştirebilir, gereksiz özellik eklemez ve her aşamada derlenebilir, test edilebilir bir uygulama ortaya çıkar.
